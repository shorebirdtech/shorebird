## Shorebird CodePush Protocol

The Shorebird CodePush Protocol is a Dart library which contains common interfaces used by Shorebird CodePush.

### Regenerating from the OpenAPI spec

Everything under `lib/src/` and `test/generated/` is generated by
[space_gen](https://github.com/eseidel/space_gen) from `openapi.yaml` in
this package: a copy of the public Shorebird CodePush API spec served at
[api.shorebird.dev/openapi.yaml](https://api.shorebird.dev/openapi.yaml).
Regenerate from the repo root:

```sh
dart run packages/shorebird_code_push_protocol/tool/gen.dart
```

The server's spec is the source of truth, and the server's CI fails if
this copy says anything it doesn't. A CLI change that needs a field or
operation the server already serves adds it to `openapi.yaml` and
regenerates, in the same PR.

Hand-written files (`lib/extensions/`, `test/src/`,
`lib/shorebird_code_push_protocol.dart`) are left untouched by the
generator. The version of space_gen in use is pinned in `pubspec.yaml`.
